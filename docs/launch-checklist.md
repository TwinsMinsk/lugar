# Чек-лист запуска

Что должно быть правдой до того, как сайт станет публичным. Разделено по тому, кто это делает и что
блокирует запуск, а что нет.

Обзорный экран `/admin` показывает часть этих пунктов цифрами — начните с него.

---

## Блокирует запуск

### Данные владельца

Ни одного выдуманного факта в системе нет. Пока поле не заполнено, соответствующий элемент на сайте
**не показывается** — не «показывается пустым», а отсутствует. Проверьте раздел «Настройки»,
незаполненные помечены.

- [ ] Телефон в формате для показа и в формате E.164
- [ ] Номер для WhatsApp (цифрами, без плюса)
- [ ] Публичный email
- [ ] География работ или физический адрес — **только если он должен быть публичным**
- [ ] Юридическое наименование и NIF/CIF
- [ ] Реальные ссылки на Instagram и Facebook
- [ ] «Картинка для соцсетей» — показывается при отправке ссылки в мессенджер, лучше 1200×630
- [ ] Логотип

Логотипы EGGER / BLUM / HETTICH — **только с письменного разрешения правообладателя**. Без него
бренды остаются текстом. Это безопаснее и выглядит намеренно.

### Изображения

- [ ] Счётчик заглушек на обзорном экране равен нулю
- [ ] У каждого изображения заполнен alt-текст
- [ ] Фотографии проектов портфолио — настоящие работы студии, с правом на публикацию

Заглушка с надписью «ЗАМЕНИТЬ» на публичной странице — это то, что увидит клиент.

### Юридические страницы

- [ ] Политика конфиденциальности вычитана юристом
- [ ] Политика cookie вычитана юристом
- [ ] Обе опубликованы на всех трёх языках

Текст, сгенерированный по шаблону, не является юридическим документом. Испания — юрисдикция GDPR,
и форма собирает персональные данные с первого дня.

### Тексты

- [ ] Испанские тексты вычитаны носителем
- [ ] Английские тексты вычитаны носителем

Испанский — основной рынок. Тексты в системе написаны человеком, но не носителем.

### Инфраструктура

- [ ] Домен привязан, https работает
- [ ] `NEXT_PUBLIC_APP_URL` — боевой домен без слэша на конце
- [ ] `BETTER_AUTH_SECRET` и `PREVIEW_SECRET` — длинные случайные строки, **не те, что в разработке**
- [ ] Объектное хранилище настроено: `S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`,
      `S3_SECRET_ACCESS_KEY`, `NEXT_PUBLIC_MEDIA_BASE_URL`
- [ ] `STORAGE_DRIVER` **не** равен `local` — Railway стирает файлы на диске при каждом деплое
- [ ] Миграции применены на боевой базе
- [ ] Первый владелец создан командой `npm run auth:bootstrap`

  Скрипт отказывается работать, если владелец уже существует, поэтому второго администратора им не
  создать. Переменную `INITIAL_OWNER_EMAIL` после запуска можно убрать.
- [ ] Резервное копирование базы включено

### Доступ

- [ ] Пароль владельца не совпадает ни с чем из разработки
- [ ] Роли розданы по минимуму: редактору не нужны заявки
- [ ] Приглашения, отправленные для проверки, отозваны

## Не блокирует, но проверьте

### Почта

- [ ] `RESEND_API_KEY` и `EMAIL_FROM` заданы, домен отправителя верифицирован

Без почты приглашения всё равно работают — ссылка показывается для передачи вручную. Но резервное
уведомление о заявке, когда WhatsApp недоступен, уходит именно почтой.

### WhatsApp

См. `whatsapp-setup.md`. Сайт работает без интеграции: заявки собираются, кнопки ведут на `wa.me`.

- [ ] Верификация бизнеса у Meta пройдена
- [ ] Webhook подключён и проходит проверку
- [ ] Шаблон уведомления о заявке одобрен
- [ ] Сервис-воркер запущен в Railway
- [ ] Проверено вживую: входящее сообщение появляется в карточке

### Аналитика

- [ ] `NEXT_PUBLIC_GA_MEASUREMENT_ID` / `NEXT_PUBLIC_META_PIXEL_ID` заданы, если аналитика нужна
- [ ] Переключатель «Включить аналитику» в настройках включён

Теги не срабатывают, пока посетитель не даст согласие, — независимо от этих настроек.

### SEO

- [ ] `/sitemap.xml` открывается и содержит опубликованные страницы
- [ ] `/robots.txt` закрывает `/admin`
- [ ] Сайт добавлен в Google Search Console

## Проверено автоматически

Эти утверждения покрыты тестами и проверяются на каждой сборке. Отдельно проверять руками не нужно;
если что-то из этого сломается, сборка не пройдёт.

| Область | Что доказано |
| --- | --- |
| Доступ | Аноним не читает данные админки; редактор отбивается от заявок и настроек **сервером**, а не скрытым пунктом меню |
| CMS | Черновик не виден публично; публикация меняет сайт; откат возвращает прошлую версию; невалидный блок не сохраняется |
| Медиа | Занятое опубликованной страницей изображение не удаляется; точка фокуса переживает сохранение |
| Заявки | Отправка формы = ровно одна заявка; UTM доезжают; спам отбивается; выгрузка обезвреживает формулы Excel |
| Редиректы | Смена адреса сохраняет старую ссылку; кольцо отклоняется; живая страница выигрывает у старого правила |
| WhatsApp | Неверная подпись → 403; подпись по пересобранному JSON отвергается; дубль события идемпотентен; три воркера на 30 задач берут каждую ровно раз |
| Окно 24 ч | Закрывается за пять минут до срока; неизвестный номер считается закрытым |
| SEO | У опубликованного маршрута есть canonical и hreflang; черновики и админка в sitemap не попадают |
| Доступность | Публичные страницы и все экраны админки проходят axe по WCAG 2.1 A/AA; баннер cookie отклоняется с клавиатуры не сложнее, чем принимается |
| Скорость | Бюджет по весу страницы держится (сегодня ~400 КБ, из них 208 КБ JS); CLS ровно 0; на критическом пути нет запросов к чужим доменам |

## Чего в системе нет намеренно

Проверьте, что это совпадает с ожиданиями, до запуска, а не после.

- **Магазина, корзины, оплаты.** Сайт ведёт к разговору, а не к покупке.
- **Регистрации посетителей.** Личных кабинетов нет.
- **Автоматического объединения дублей.** Повторное обращение помечается, решает человек.
- **Гарантии однократной доставки в WhatsApp.** См. `whatsapp-setup.md`.
- **Произвольного HTML в контенте.** Блоки типизированы, вёрстку из редактора сломать нельзя.

## Что ещё не сделано

Честный список на момент написания. Ничто из этого не мешает публичному запуску, но и не появится
само.

- Разделы «Контакты» и «Проекты» в CRM: данные пишутся, отдельных экранов нет. Контакт виден в
  карточке заявки.
- Замеры на реальных сетях и устройствах: вес страницы и CLS закреплены бюджетом (см. таблицу
  выше), но всё измерено на локальной машине по localhost. Как сайт открывается с мобильного
  интернета в Испании — не проверено; это делается на боевом домене после запуска.
- Вес изображений: сейчас на страницах стоят заглушки, настоящих фотографий нет. Именно они
  обычно и определяют скорость — бюджет придётся пересмотреть после загрузки реальных фото.
- Проверка живым скринридером: автоматика ловит контраст, имена и роли, но не то, как экран
  звучит целиком. NVDA или VoiceOver по ключевым сценариям — отдельная задача для человека.
- Шаблоны с подстановками при закрытом окне 24 ч: выбрать можно только шаблон без переменных.
